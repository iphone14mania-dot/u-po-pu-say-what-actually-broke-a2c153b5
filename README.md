A tiny Node program that writes one line of software error copy to `/output/entry.txt` — the brutal truth about a double charge: the payment went through twice because our retry button retried too hard, the duplicate is refunded, and the user's bank just needs a day to believe us. 145 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
